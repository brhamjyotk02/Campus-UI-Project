🎓 CampusHub AI — The Ultimate Smart College Ecosystem

One Campus. One Platform. A Smarter Experience.
CampusHub AI is a smart college ecosystem designed to bring students, faculty, and essential campus activities together on a single platform. It aims to simplify campus life by providing an organized and user-friendly interface for accessing important academic resources and campus services.

✨ Features

🔐 Authentication System — Login and registration with form validation.

👤 User Profile — Profile dropdown and logout functionality.

🏫 Campus Directory — Explore and search student and faculty information.

📝 Assignment Manager — Manage academic assignments in one place.

🔔 Notifications — Stay updated with important activities and announcements.

🛡️ Protected Routes — Restrict access to pages based on authentication state.

📱 Responsive UI — User-friendly interface across different screen sizes.

⚡ Reusable Components — Maintainable and modular React architecture.

🛠️ Tech Stack

Frontend: React.js

Styling: Tailwind CSS

Build Tool: Vite

Routing: React Router

State Management: React Context API

Language: JavaScript, HTML, CSS and React

📂 Project Modules

The project is organized into the following major modules:

Authentication & Core UI — Login, registration, validation, global authentication state, profile dropdown, and protected routes.

Campus Directory — Student and faculty directory with search and filtering functionality.

Assignment Manager — Assignment-related features for organizing academic tasks.

Notifications — Updates and notifications to keep users informed.

🎯 Project Objective

The objective of CampusHub AI is to create a centralized digital platform that makes campus-related activities more accessible, organized, and convenient. By bringing essential college services into one ecosystem, the project aims to improve the overall digital campus experience.

👥 Team Contributions

The project is developed collaboratively, with responsibilities divided across core UI and authentication, campus directory, assignment management, and notifications.
