# CampusHub AI — Integrated Project

## Run the project
1. Install Node.js (LTS).
2. Extract this folder.
3. Open a terminal inside the project folder.
4. Run `npm install`
5. Run `npm run dev`
6. Open the local URL shown by Vite (usually http://localhost:5173).

## Demo login
- Student: student@campushub.local / student123
- Teacher: teacher@campushub.local / teacher123

## Notes
- The project uses React, Vite, React Router and lucide-react.
- Demo accounts and app data are stored in browser localStorage; this is a frontend demo, not production authentication.
- Main modules include dashboard, timetable, attendance, notes, assignments, focus zone, profile, clubs, events, complaints and campus assistant.

### Notifications
A separate Notifications page is available from the student and teacher sidebar, and from the dashboard Quick Actions. Open `/notifications` to view updates, mark individual notifications as read, or mark all as read. Notification data is stored in browser localStorage for this demo.
